## A targeted route to cosmology

The method combines a gravitational-wave distance measurement with the redshift of a known host galaxy. By searching at a source selected from electromagnetic observations, the analysis removes the need to identify a host from a large gravitational-wave localisation region.

Using simulations informed by present observations, we show that a realistic Chinese Pulsar Timing Array data set could constrain the Hubble constant to a precision of roughly 2 km s<sup>−1</sup> Mpc<sup>−1</sup> for a favourable targeted source. The work also explores how multiple sources and host confusion affect the measurement.
